# Use OpenAny with your agent

Choose an example, copy the prompt into your agent, and describe what you want to find. Your agent uses OpenAny to retrieve the data and explain the results.

Each prompt starts with `Read https://openany.si/SKILL.md, then …` so your agent can read the OpenAny instructions and carry out your request. Follow any setup or budget questions from your agent, and configure credentials locally. Never paste API keys into the chat.

## Examples

- [Research market interest](market-research/README.md): compare search interest for two product categories using Google Trends.
- [Track competitor prices](competitor-price-monitor/README.md): collect Sony and Bose shopping listings and reuse a snapshot for later comparisons.
- [Look up cryptocurrency prices](crypto-data/README.md): retrieve BTC, ETH, and SOL prices with 24-hour changes and update times.
- [Search Facebook Ad Library](facebook-ad-library/README.md): find active ads matching a keyword, see who is advertising, and open the original ads.

Each example includes a ready-to-use prompt and real API results. The Facebook prompt comes from the linked session; the other prompts describe the requests used to collect their saved results. Paid searches use your OpenAny balance; prices and results can change.
